## Display

```csharp
static class Display
```

Display settings: frame rate, scale, inversion, mosaic, flipping and offset (C: `pd->display`, Lua: `playdate.display`).

#### `static int Width { get; }`

Display width in pixels at the current scale: 400 at scale 1, 200 at scale 2, ...

#### `static int Height { get; }`

Display height in pixels at the current scale: 240 at scale 1, 120 at scale 2, ...

#### `static float RefreshRate { get; set; }`

The target frame rate (default 30, maximum 50). 0 calls `Game.Update` as often as possible.

#### `static float FPS { get; }`

The frame rate actually achieved, which can be lower than `RefreshRate` when frames take too long.

#### `static void SetRefreshRate(float rate)`

Sets the target frame rate; same as setting `RefreshRate`.

- `rate`: Frames per second, up to 50; 0 = as fast as possible.

#### `static void SetInverted(bool inverted)`

Shows the display inverted (white on black) when true.

- `inverted`: True for white-on-black, false for normal.

#### `static void SetScale(uint scale)`

Scales up the top-left part of the frame buffer to fill the screen: 1, 2, 4 or 8. At scale 2 the game draws into a 200x120 area and each pixel shows as 2x2.

- `scale`: 1, 2, 4 or 8. Other values are ignored.

#### `static void SetMosaic(uint x, uint y)`

Adds a mosaic effect; x and y are 0 (off) to 3.

- `x`: Horizontal mosaic amount, 0 (off) to 3.
- `y`: Vertical mosaic amount, 0 (off) to 3.

#### `static void SetFlipped(bool x, bool y)`

Mirrors the display horizontally and/or vertically.

- `x`: Mirror left-right.
- `y`: Mirror top-bottom.

#### `static void SetOffset(int x, int y)`

Moves the whole image by (x, y) pixels (e.g. for a screen shake); uncovered areas show the background color (`Graphics.SetBackgroundColor`).

- `x`: Horizontal shift in pixels (positive = right).
- `y`: Vertical shift in pixels (positive = down).

## TileMap

```csharp
struct TileMap : IDisposable
```

A grid of tiles drawn from a `BitmapTable` (C: LCDTileMap, Lua: playdate.graphics.tilemap). Create with `Create`, dispose when done; a tile map can also be a sprite's image (`Sprite.Tilemap`).

#### `readonly LCDTileMap* Handle`

The native pointer.

#### `TileMap(LCDTileMap* handle)`

Wraps a native tile map pointer.

- `handle`: A native tile map pointer; this struct doesn't take ownership.

#### `static TileMap Create()`

Creates an empty tile map. Set `ImageTable` and the size next.

#### `bool IsNull { get; }`

True if this handle doesn't refer to a tile map.

#### `BitmapTable ImageTable { get; set; }`

The image table supplying the tile images (not owned by the tile map).

#### `void SetSize(int tilesWide, int tilesHigh)`

Sets the size in tiles.

- `tilesWide`: Number of columns, 1 or more.
- `tilesHigh`: Number of rows, 1 or more.

#### `void GetSize(out int tilesWide, out int tilesHigh)`

Gets the size in tiles.

- `tilesWide`: Receives the number of columns.
- `tilesHigh`: Receives the number of rows.

#### `void GetPixelSize(out uint width, out uint height)`

Gets the size in pixels (tile size times the number of tiles).

- `width`: Receives the width in pixels (columns times tile width).
- `height`: Receives the height in pixels.

#### `void SetTiles(ReadOnlySpan<ushort> indexes, int rowWidth)`

Sets all tiles at once, row by row; the map becomes `rowWidth` tiles wide and indexes.Length / rowWidth tiles high (the length must be a multiple of rowWidth).

- `indexes`: Image table indexes (0-based), row by row; its length must be a multiple of `rowWidth`.
- `rowWidth`: Tiles per row, 1 or more.

#### `void SetTile(int x, int y, ushort index)`

Sets the tile at grid position (x, y) to image `index` (0-based) of the image table.

- `x`: Column, 0 to width - 1.
- `y`: Row, 0 to height - 1.
- `index`: Image table index, 0 to the table's Count - 1.

#### `int GetTile(int x, int y)`

Returns the image index of the tile at (x, y), or -1 outside the map.

- `x`: Column, 0 to width - 1.
- `y`: Row, 0 to height - 1.

#### `void Draw(float x, float y)`

Draws the map with its top-left corner at (x, y).

- `x`: Screen x of the map's left edge (can be negative to scroll).
- `y`: Screen y of the map's top edge.

#### `void Dispose()`

Frees the tile map (not its image table).

## VideoPlayer

```csharp
struct VideoPlayer : IDisposable
```

Renders frames of a .pdv video (C: LCDVideoPlayer, Lua: playdate.graphics.video). Videos have no sound; play the audio separately with a `FilePlayer`.

#### `readonly LCDVideoPlayer* Handle`

The native pointer.

#### `VideoPlayer(LCDVideoPlayer* handle)`

Wraps a native video player pointer.

- `handle`: A native video player pointer; this struct doesn't take ownership.

#### `static VideoPlayer Load(string path)`

Opens a .pdv file from the pdx. Stops the game with an error if it can't be opened.

- `path`: Path of the .pdv file in the pdx, without extension.

#### `bool IsNull { get; }`

True if this handle doesn't refer to a player.

#### `bool SetContext(Bitmap context)`

Renders frames into `context` instead of the screen (use an opaque bitmap).

- `context`: The bitmap to render into; it should be at least the video's size.

Returns: False on error; see `Error`.

#### `void UseScreenContext()`

Renders frames directly to the screen.

#### `Bitmap Context { get; }`

The bitmap frames are rendered into; if none was set, one with the video's size is created.

#### `bool RenderFrame(int frame)`

Renders frame number `frame` (0-based) into the context.

- `frame`: Frame number, 0 to frameCount - 1 (see `GetInfo`).

Returns: False on error; see `Error`.

#### `string Error { get; }`

Text describing the last error.

#### `void GetInfo(out int width, out int height, out float frameRate, out int frameCount, out int currentFrame)`

Gets the video's size, frame rate, number of frames and the frame last rendered.

- `width`: Receives the video width in pixels.
- `height`: Receives the video height in pixels.
- `frameRate`: Receives the frames per second the video was made for.
- `frameCount`: Receives the number of frames.
- `currentFrame`: Receives the last frame rendered.

#### `void Dispose()`

Frees the player.
