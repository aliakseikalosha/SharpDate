## FileSystem

```csharp
static class FileSystem
```

Reading and writing files (C: `pd->file`, Lua: `playdate.file`).

Each game can read its own pdx (read-only) and read and write its data folder (Data/<bundleID> on the device, Disk/Data/<bundleID> next to the Simulator). Paths are relative, e.g. "save.json" or "levels/1.bin". `ReadAllBytes` and `ReadAllText` look in the data folder first, then in the pdx; with `Open` the `FileOptions` decide. Methods returning bool report failure with false; `LastError` has the reason. At most 64 files can be open at once.

#### `static string LastError { get; }`

The last file error message, or null.

#### `static PDFile Open(string path, FileOptions mode)`

Opens a file. Returns a null `PDFile` on failure (see `LastError`).

- `path`: Relative path, e.g. "save.json".
- `mode`: Where to look and how to open (see `FileOptions`).

#### `static bool Exists(string path)`

True if a file or folder exists at `path`.

- `path`: Relative path of a file or folder.

#### `static bool Stat(string path, out FileStat stat)`

Gets size, folder flag and modification time; false if nothing exists at `path`.

- `path`: Relative path.
- `stat`: Receives size, folder flag and modification time.

#### `static bool Mkdir(string path)`

Creates a folder in the data folder. Intermediate folders are not created.

- `path`: The folder to create; its parent must exist.

#### `static bool Unlink(string path, bool recursive = false)`

Deletes a file, or a folder with everything in it when `recursive` is true.

- `path`: The file or folder to delete.
- `recursive`: Delete a folder with all its contents (a non-empty folder fails without it).

#### `static bool Rename(string from, string to)`

Renames or moves a file, replacing an existing file at `to`.

- `from`: Current path.
- `to`: New path; its folder must exist.

#### `static List<string> ListFiles(string path, bool showHidden = false)`

Lists the names in a folder (not recursive); folder names end with '/'. "" lists the top level.

- `showHidden`: Include names starting with a dot.
- `path`: Folder to list; "" for the top level.

#### `static byte[] ReadAllBytes(string path)`

Reads a whole file (data folder first, then the pdx).

- `path`: Relative path.

Returns: The contents, or null if the file doesn't exist.

#### `static string ReadAllText(string path)`

Reads a whole UTF-8 text file (data folder first, then the pdx).

- `path`: Relative path.

Returns: The text, or null if the file doesn't exist.

#### `static bool WriteAllBytes(string path, ReadOnlySpan<byte> data)`

Creates or replaces a file in the data folder.

- `path`: Relative path in the data folder; its folder must exist.
- `data`: The bytes to write.

#### `static bool WriteAllText(string path, string text)`

Creates or replaces a UTF-8 text file in the data folder.

- `path`: Relative path in the data folder; its folder must exist.
- `text`: The text, written as UTF-8 without BOM.

## PDFile

```csharp
struct PDFile : IDisposable
```

An open file (C: SDFile, Lua: playdate.file.file), from `FileSystem.Open`. A struct around the native handle; close it with `Dispose` (a `using` statement does it).

#### `readonly SDFile* Handle`

The native handle.

#### `PDFile(SDFile* handle)`

Wraps a native file handle.

- `handle`: A native file handle; this struct doesn't take ownership.

#### `bool IsNull { get; }`

True if the file could not be opened.

#### `int Read(Span<byte> buffer)`

Reads up to buffer.Length bytes.

- `buffer`: Receives the bytes; reads up to its length.

Returns: Bytes read, 0 at the end of the file, -1 on error.

#### `int Read(void* buffer, uint length)`

Reads up to `length` bytes into native memory.

- `buffer`: Native memory of at least `length` bytes.
- `length`: Maximum bytes to read.

Returns: Bytes read, 0 at the end of the file, -1 on error.

#### `int Write(ReadOnlySpan<byte> data)`

Writes bytes at the current position.

- `data`: The bytes to write.

Returns: Bytes written, or -1 on error.

#### `int Write(string text)`

Writes text as UTF-8.

- `text`: Text written as UTF-8.

Returns: Bytes written, or -1 on error.

#### `int Flush()`

Writes buffered data to the disk now.

Returns: Bytes written, or -1 on error.

#### `int Tell()`

The current read/write position, or -1 on error.

#### `int Seek(int position, SeekOrigin origin = SeekOrigin.Begin)`

Moves the read/write position.

- `position`: Byte offset relative to `origin` (may be negative from `SeekOrigin.Current` or `SeekOrigin.End`).
- `origin`: Start, current position or end.

Returns: 0 on success, -1 on error.

#### `void Dispose()`

Closes the file.
