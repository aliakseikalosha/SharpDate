## Pattern

```csharp
class Pattern : IDisposable
```

An 8x8 pattern (8 rows of pixel data followed by 8 rows of mask) in native memory, usable as an `LCDColor`. The memory stays valid until `Dispose`.

#### `Pattern(byte r0, byte r1, byte r2, byte r3, byte r4, byte r5, byte r6, byte r7)`

Creates an opaque pattern from 8 rows of pixel bits (1 = white).

- `r0`: Row 0 (top) of the 8x8 tile: bit 7 = leftmost pixel, 1 = white, 0 = black.
- `r1`: Row 1.
- `r2`: Row 2.
- `r3`: Row 3.
- `r4`: Row 4.
- `r5`: Row 5.
- `r6`: Row 6.
- `r7`: Row 7 (bottom).

#### `Pattern(byte r0, byte r1, byte r2, byte r3, byte r4, byte r5, byte r6, byte r7, byte m0, byte m1, byte m2, byte m3, byte m4, byte m5, byte m6, byte m7)`

Creates a pattern with explicit mask rows (mask bit 1 = opaque).

- `r0`: Pixel row 0 (top): bit 7 = leftmost pixel, 1 = white, 0 = black.
- `r1`: Pixel row 1.
- `r2`: Pixel row 2.
- `r3`: Pixel row 3.
- `r4`: Pixel row 4.
- `r5`: Pixel row 5.
- `r6`: Pixel row 6.
- `r7`: Pixel row 7 (bottom).
- `m0`: Mask row 0: bit 7 = leftmost pixel, 1 = drawn, 0 = transparent.
- `m1`: Mask row 1.
- `m2`: Mask row 2.
- `m3`: Mask row 3.
- `m4`: Mask row 4.
- `m5`: Mask row 5.
- `m6`: Mask row 6.
- `m7`: Mask row 7.

#### `static Pattern FromBitmap(Bitmap bitmap, int x, int y)`

Creates a pattern from the 8x8 block of `bitmap` whose top-left corner is (x, y), including its mask (C: setColorToPattern).

- `bitmap`: The source bitmap.
- `x`: Left of the 8x8 block, 0 to width - 8.
- `y`: Top of the 8x8 block, 0 to height - 8.

#### `static Pattern Gray50 { get; }`

A 50% checkerboard dither.

#### `byte* Data { get; }`

The 16 pattern bytes: 8 rows of pixels (bit 7 = leftmost, 1 = white), then 8 rows of mask (1 = opaque).

#### `LCDColor Color { get; }`

The pattern as a color for the drawing functions. Valid until `Dispose`.

#### `static implicit operator LCDColor(Pattern pattern)`

Lets a pattern be passed wherever a color is expected.

#### `void Dispose()`

Frees the pattern memory. Don't draw with the pattern afterwards.

## Graphics

```csharp
static class Graphics
```

Drawing on the screen or into a bitmap: shapes, text, bitmaps, clipping, stencils and direct frame buffer access (C: `pd->graphics`, Lua: `playdate.graphics`).

Coordinates are in pixels, (0, 0) is the top-left corner and the screen is `Width` x `Height`. Drawing goes to the screen unless a bitmap was pushed with `PushContext`. Drawing state (offset, clip rect, draw mode, stencil, font) is reset at the start of every frame. Colors are `LCDColor` values: a `SolidColor` or a `Pattern`. See docs/reference/graphics.md.

#### `const int Width = PD.LCD_COLUMNS`

Screen width in pixels (400).

#### `const int Height = PD.LCD_ROWS`

Screen height in pixels (240).

#### `const int RowSize = PD.LCD_ROWSIZE`

Bytes per frame-buffer row (52: 50 bytes of pixels plus 2 bytes of padding).

#### `static void Clear(LCDColor color)`

Fills the whole screen (or current bitmap context) with `color` (Lua: playdate.graphics.clear).

- `color`: Fill color or pattern.

#### `static void SetBackgroundColor(SolidColor color)`

Sets the color used where the display is offset (`Display.SetOffset`) and to clear dirty areas behind sprites.

- `color`: `SolidColor.Black`, `SolidColor.White` or `SolidColor.Clear`.

#### `static DrawMode SetDrawMode(DrawMode mode)`

Sets how bitmaps and text are drawn (Lua: setImageDrawMode).

- `mode`: The new mode.

Returns: The previous mode, so it can be restored.

#### `static void SetDrawOffset(int dx, int dy)`

Offsets every following drawing call by (dx, dy), e.g. to scroll a camera over a world larger than the screen. Sprites are drawn with the offset too unless `Sprite.IgnoresDrawOffset` is set.

- `dx`: Added to every x coordinate (negative scrolls the view right).
- `dy`: Added to every y coordinate.

#### `static void SetClipRect(int x, int y, int width, int height)`

Restricts drawing to a rectangle given in world coordinates (it is moved by the draw offset). Cleared at the start of every frame.

- `x`: Left edge in world coordinates.
- `y`: Top edge in world coordinates.
- `width`: Width in pixels, 1 or more.
- `height`: Height in pixels, 1 or more.

#### `static void SetScreenClipRect(int x, int y, int width, int height)`

Restricts drawing to a rectangle given in screen coordinates (ignores the draw offset).

- `x`: Left edge on screen, 0-399.
- `y`: Top edge on screen, 0-239.
- `width`: Width in pixels, 1 or more.
- `height`: Height in pixels, 1 or more.

#### `static void ClearClipRect()`

Removes the clip rect.

#### `static void SetLineCapStyle(LineCapStyle style)`

Sets how the ends of lines drawn with `DrawLine` look.

- `style`: The cap style for following lines.

#### `static void SetFont(Font font)`

Sets the font used by the text functions. Without a font the system font (Asheville Sans 14 Light) is used.

- `font`: A loaded font; keep it alive while it is set.

#### `static void SetTextTracking(int tracking)`

Sets extra spacing in pixels between characters (can be negative).

- `tracking`: Extra pixels between characters (default 0, can be negative).

#### `static int GetTextTracking()`

Returns the current text tracking.

#### `static void SetTextLeading(int lineHeightAdjustment)`

Adds `lineHeightAdjustment` pixels to the font's line spacing for multi-line text.

- `lineHeightAdjustment`: Extra pixels between lines (default 0, can be negative).

#### `static void SetStencilImage(Bitmap stencil, bool tile = false)`

Only draws where `stencil` is white. With `tile` the stencil repeats; tiled stencils must be a multiple of 32 pixels wide.

- `stencil`: The stencil, in screen coordinates; white = draw, black = don't.
- `tile`: Repeat the stencil over the screen; it must then be a multiple of 32 pixels wide.

#### `static void ClearStencil()`

Removes the stencil.

#### `static void PushContext(Bitmap target)`

Redirects drawing into `target` (or the screen when target is null) until `PopContext`.

- `target`: The bitmap to draw into; a null bitmap (`default`) draws to the screen with a fresh drawing state.

#### `static void PopContext()`

Ends drawing into the bitmap pushed with `PushContext` and restores the previous drawing settings.

#### `static void DrawLine(int x1, int y1, int x2, int y2, int width, LCDColor color)`

Draws a line from (x1, y1) to (x2, y2), `width` pixels thick.

- `x1`: Start x.
- `y1`: Start y.
- `x2`: End x.
- `y2`: End y.
- `width`: Line thickness in pixels, 1 or more.
- `color`: Color or pattern.

#### `static void FillTriangle(int x1, int y1, int x2, int y2, int x3, int y3, LCDColor color)`

Fills the triangle with corners (x1, y1), (x2, y2), (x3, y3).

- `x1`: First corner x.
- `y1`: First corner y.
- `x2`: Second corner x.
- `y2`: Second corner y.
- `x3`: Third corner x.
- `y3`: Third corner y.
- `color`: Color or pattern.

#### `static void DrawRect(int x, int y, int width, int height, LCDColor color)`

Draws a 1-pixel rectangle outline with its top-left corner at (x, y).

- `x`: Left edge.
- `y`: Top edge.
- `width`: Width in pixels.
- `height`: Height in pixels.
- `color`: Color or pattern of the 1-pixel outline.

#### `static void FillRect(int x, int y, int width, int height, LCDColor color)`

Fills a rectangle with its top-left corner at (x, y).

- `x`: Left edge.
- `y`: Top edge.
- `width`: Width in pixels.
- `height`: Height in pixels.
- `color`: Color or pattern.

#### `static void DrawRoundRect(int x, int y, int width, int height, int radius, int lineWidth, LCDColor color)`

Draws a rounded rectangle outline inside the given rectangle.

- `radius`: Corner radius in pixels.
- `lineWidth`: Outline thickness.
- `x`: Left edge.
- `y`: Top edge.
- `width`: Width in pixels.
- `height`: Height in pixels.
- `color`: Color or pattern.

#### `static void FillRoundRect(int x, int y, int width, int height, int radius, LCDColor color)`

Fills a rounded rectangle.

- `radius`: Corner radius in pixels.
- `x`: Left edge.
- `y`: Top edge.
- `width`: Width in pixels.
- `height`: Height in pixels.
- `color`: Color or pattern.

#### `static void DrawEllipse(int x, int y, int width, int height, int lineWidth, float startAngle, float endAngle, LCDColor color)`

Draws an ellipse (or an arc) inside the rectangle {x, y, width, height}; the line is inset from the edges.

- `lineWidth`: Stroke width.
- `startAngle`: Start of the arc in degrees, clockwise from 12 o'clock.
- `endAngle`: End of the arc. Use the same value as `startAngle` (e.g. 0, 0) for a full ellipse.
- `x`: Left of the bounding rectangle.
- `y`: Top of the bounding rectangle.
- `width`: Width of the bounding rectangle (diameter for a circle).
- `height`: Height of the bounding rectangle.
- `color`: Color or pattern.

#### `static void FillEllipse(int x, int y, int width, int height, float startAngle, float endAngle, LCDColor color)`

Fills an ellipse inside the rectangle, or a pie wedge when the angles differ.

- `startAngle`: Start angle in degrees, clockwise from 12 o'clock.
- `endAngle`: End angle. Equal angles fill the whole ellipse.
- `x`: Left of the bounding rectangle.
- `y`: Top of the bounding rectangle.
- `width`: Width of the bounding rectangle.
- `height`: Height of the bounding rectangle.
- `color`: Color or pattern.

#### `static void SetPixel(int x, int y, LCDColor color)`

Sets one pixel. Slow for bulk work (about 20,000 calls drop a frame below 30 fps); use `GetFrame` to write many pixels.

- `x`: Column.
- `y`: Row.
- `color`: Color (a pattern uses its pixel at this position).

#### `static void FillPolygon(ReadOnlySpan<int> coords, LCDColor color, PolygonFillRule fillRule = PolygonFillRule.NonZero)`

Fills a polygon. `coords` holds alternating x and y values; the last point is joined to the first.

- `coords`: x0, y0, x1, y1, ... at least 3 points (6 values), an even count.
- `color`: Color or pattern.
- `fillRule`: How overlapping areas are filled.

#### `static void DrawBitmap(Bitmap bitmap, int x, int y, BitmapFlip flip = BitmapFlip.Unflipped)`

Draws a bitmap with its top-left corner at (x, y).

- `bitmap`: The image.
- `x`: Screen x of its left edge.
- `y`: Screen y of its top edge.
- `flip`: Mirroring.

#### `static void TileBitmap(Bitmap bitmap, int x, int y, int width, int height, BitmapFlip flip = BitmapFlip.Unflipped)`

Repeats the bitmap to fill the rectangle {x, y, width, height}.

- `bitmap`: The image to repeat.
- `x`: Left of the area (and of the first copy).
- `y`: Top of the area.
- `width`: Width of the area in pixels.
- `height`: Height of the area in pixels.
- `flip`: Mirroring of each copy.

#### `static void DrawScaledBitmap(Bitmap bitmap, int x, int y, float xScale, float yScale)`

Draws a bitmap scaled by (xScale, yScale) with its top-left corner at (x, y). Negative scales mirror it.

- `bitmap`: The image.
- `x`: Left edge of the result.
- `y`: Top edge of the result.
- `xScale`: Horizontal factor (1 = original, 2 = double, negative = mirrored).
- `yScale`: Vertical factor.

#### `static void DrawRotatedBitmap(Bitmap bitmap, int x, int y, float rotation, float centerX, float centerY, float xScale, float yScale)`

Draws a bitmap scaled, then rotated by `rotation` degrees (clockwise), so that the point (centerX, centerY) of the bitmap lands on (x, y). The center is a fraction of the bitmap's size: 0.5, 0.5 is its middle, 0, 0 its top-left corner.

- `bitmap`: The image.
- `x`: Screen x where the center point lands.
- `y`: Screen y where the center point lands.
- `rotation`: Clockwise rotation in degrees (any value; 360 = full turn).
- `centerX`: Horizontal position of the pivot in the image, 0 (left) to 1 (right).
- `centerY`: Vertical position of the pivot, 0 (top) to 1 (bottom).
- `xScale`: Horizontal scale, applied before rotating (1 = original).
- `yScale`: Vertical scale.

#### `static bool CheckMaskCollision(Bitmap bitmap1, int x1, int y1, BitmapFlip flip1, Bitmap bitmap2, int x2, int y2, BitmapFlip flip2, LCDRect rect)`

Pixel-perfect collision test: true if any opaque pixel of `bitmap1` at (x1, y1) overlaps an opaque pixel of `bitmap2` at (x2, y2), considering only the area inside `rect` (which must not be empty).

- `bitmap1`: First image.
- `x1`: Left of the first image.
- `y1`: Top of the first image.
- `flip1`: Mirroring of the first image.
- `bitmap2`: Second image.
- `x2`: Left of the second image.
- `y2`: Top of the second image.
- `flip2`: Mirroring of the second image.
- `rect`: Only pixels inside this rectangle count; must not be empty.

#### `static int DrawText(string text, int x, int y)`

Draws text with the current font, top-left corner at (x, y). Newlines start a new line.

- `text`: The text; \n starts a new line. null draws nothing.
- `x`: Left edge.
- `y`: Top edge of the first line.

Returns: The width of the drawn text in pixels.

#### `static int DrawText(ReadOnlySpan<byte> utf8, int x, int y)`

Draws UTF-8 text, e.g. `Graphics.DrawText("Hello"u8, x, y)` (no string conversion at all).

- `utf8`: UTF-8 text.
- `x`: Left edge.
- `y`: Top edge of the first line.

Returns: The width of the drawn text in pixels.

#### `static int DrawText(ReadOnlySpan<char> text, int x, int y)`

Draws a span of characters, e.g. a number formatted into a stack buffer, without allocating a string.

- `text`: The characters.
- `x`: Left edge.
- `y`: Top edge of the first line.

Returns: The width of the drawn text in pixels.

#### `static void DrawTextInRect(string text, int x, int y, int width, int height, TextWrappingMode wrap = TextWrappingMode.Word, TextAlignment align = TextAlignment.Left)`

Draws text wrapped and aligned inside the rectangle {x, y, width, height}; text that doesn't fit is cut off.

- `text`: The text; \n forces a line break.
- `x`: Left of the box.
- `y`: Top of the box.
- `width`: Box width in pixels; lines wrap at it.
- `height`: Box height in pixels; lines below it are not drawn.
- `wrap`: Where lines may break.
- `align`: Horizontal alignment of each line.

#### `static int GetTextWidth(Font font, string text, int tracking = 0)`

Returns the width in pixels of a single line of text in `font`.

- `tracking`: Extra spacing between characters, as set with `SetTextTracking`.
- `font`: The font to measure with.
- `text`: One line of text.

#### `static int GetTextHeightForMaxWidth(Font font, string text, int maxWidth, TextWrappingMode wrap = TextWrappingMode.Word, int tracking = 0, int extraLeading = 0)`

Returns the height of `text` when wrapped to `maxWidth` pixels, to size a box before calling `DrawTextInRect`.

- `font`: The font to measure with.
- `text`: The text.
- `maxWidth`: Width in pixels the text wraps at.
- `wrap`: Where lines may break.
- `tracking`: Extra pixels between characters.
- `extraLeading`: Extra pixels between lines.

#### `static Span<byte> GetFrame()`

The frame buffer being drawn: 240 rows of `RowSize` bytes, 1 bit per pixel, bit 7 of a byte is the leftmost pixel, 1 = white. After writing to it call `MarkUpdatedRows`.

#### `static Span<byte> GetDisplayFrame()`

The frame buffer currently shown on the display.

#### `static byte* GetFramePointer()`

The working frame buffer as a raw pointer (see `GetFrame`).

#### `static void MarkUpdatedRows(int start, int end)`

Tells the display which rows changed after writing to `GetFrame` directly; both ends are included (MarkUpdatedRows(0, 239) refreshes everything).

- `start`: First changed row, 0-239.
- `end`: Last changed row, start-239 (included).

#### `static void Display()`

Copies the frame buffer to the display immediately (normally done after Update returns).

#### `static Bitmap CopyFrameBufferBitmap()`

Returns a copy of the working frame buffer as a new bitmap. Dispose it when done.

#### `static Bitmap GetDisplayBufferBitmap()`

Returns the last frame sent to the display as a bitmap owned by the system. Do not dispose it.

#### `static Bitmap GetDebugBitmap()`

Simulator only: a bitmap overlaid on the screen; white pixels drawn into it show as translucent red. Returns a null bitmap on the device.

## Bitmap

```csharp
struct Bitmap : IEquatable<Bitmap>, IDisposable
```

An image (C: LCDBitmap, Lua: playdate.graphics.image). A small struct around a native pointer: copying it copies the handle, not the image.

Bitmaps you `Create`, `Load`, `Copy` or get from `Rotated` are yours: `Dispose` them when done. Bitmaps returned by an image table, a sprite or the system are owned elsewhere and must not be disposed. Images are 1-bit with an optional mask (transparency).

#### `readonly LCDBitmap* Handle`

The native pointer, for the raw API (`PD.Graphics`).

#### `Bitmap(LCDBitmap* handle)`

Wraps a native bitmap pointer.

- `handle`: A native bitmap pointer; this struct doesn't take ownership (dispose only if you own it).

#### `bool IsNull { get; }`

True if this handle doesn't refer to a bitmap (e.g. a failed load).

#### `static Bitmap Create(int width, int height, LCDColor background)`

Creates a new `width` x `height` bitmap filled with `background` (use `SolidColor.Clear` for a transparent one).

- `width`: Width in pixels, 1 or more.
- `height`: Height in pixels, 1 or more.
- `background`: Initial fill; `SolidColor.Clear` gives a fully transparent image with a mask.

#### `static Bitmap Load(string path)`

Loads an image compiled into the pdx, e.g. "images/player" for Source/images/player.png (no extension). If the file can't be loaded the game stops with an error; use `TryLoad` to handle that yourself.

- `path`: Path in the pdx without extension, e.g. "images/player".

#### `static bool TryLoad(string path, out Bitmap bitmap, out string error)`

Loads an image; returns false and an error message instead of stopping the game.

- `path`: Path in the pdx without extension.
- `bitmap`: Receives the image, or a null bitmap on failure.
- `error`: Receives the reason on failure, otherwise null.

#### `void LoadInto(string path)`

Loads an image file into this existing bitmap (same size).

- `path`: Path in the pdx without extension; the image must have this bitmap's size.

#### `Bitmap Copy()`

Returns a new bitmap with the same pixels and mask.

#### `void Clear(LCDColor background)`

Fills the bitmap with `background`.

- `background`: Fill color or pattern.

#### `Bitmap Rotated(float rotation, float xScale = 1, float yScale = 1)`

Returns a new bitmap containing this one rotated by `rotation` degrees and scaled. Dispose it when done. Faster to draw repeatedly than `DrawRotated`.

- `rotation`: Clockwise rotation in degrees.
- `xScale`: Horizontal scale (1 = original).
- `yScale`: Vertical scale (1 = original).

#### `void GetData(out int width, out int height, out int rowBytes, out byte* mask, out byte* data)`

Gives raw access to the pixels: size, bytes per row, mask (null if none) and pixel data (1 bit per pixel, bit 7 = leftmost, 1 = white).

- `width`: Receives the width in pixels.
- `height`: Receives the height in pixels.
- `rowBytes`: Receives the bytes per row (rows are padded).
- `mask`: Receives the mask bits (1 = opaque), or null without a mask.
- `data`: Receives the pixel bits (1 = white); valid while the bitmap exists.

#### `int Width { get; }`

Width in pixels.

#### `int Height { get; }`

Height in pixels.

#### `SolidColor GetPixel(int x, int y)`

Returns `SolidColor.Black` or `SolidColor.White`, or `SolidColor.Clear` outside the bitmap or where the mask is transparent.

- `x`: Column, 0 to Width - 1.
- `y`: Row, 0 to Height - 1.

#### `Bitmap Mask { get; set; }`

The bitmap's mask (white = opaque). Getting it returns a new bitmap that shares this bitmap's mask memory: draw into it to change the mask, and dispose it when done. A null bitmap means no mask. Setting it copies a same-size bitmap into the mask.

#### `void Draw(int x, int y, BitmapFlip flip = BitmapFlip.Unflipped)`

Draws the bitmap with its top-left corner at (x, y).

- `x`: Screen x of the left edge.
- `y`: Screen y of the top edge.
- `flip`: Mirroring.

#### `void DrawScaled(int x, int y, float xScale, float yScale)`

Draws the bitmap scaled; negative scales mirror it.

- `x`: Left edge of the result.
- `y`: Top edge of the result.
- `xScale`: Horizontal factor (negative = mirrored).
- `yScale`: Vertical factor.

#### `void DrawRotated(int x, int y, float rotation, float centerX = 0.5f, float centerY = 0.5f, float xScale = 1, float yScale = 1)`

Draws the bitmap rotated by `rotation` degrees so that its point (centerX, centerY) (fractions of its size; 0.5, 0.5 = middle) lands on (x, y).

- `x`: Screen x where the pivot lands.
- `y`: Screen y where the pivot lands.
- `rotation`: Clockwise rotation in degrees.
- `centerX`: Pivot position in the image, 0 (left) to 1 (right); default 0.5.
- `centerY`: Pivot position, 0 (top) to 1 (bottom); default 0.5.
- `xScale`: Horizontal scale (1 = original).
- `yScale`: Vertical scale (1 = original).

#### `void Dispose()`

Frees the bitmap. Only for bitmaps you created, loaded or copied.

#### `bool Equals(Bitmap other)`

True if both handles refer to the same native bitmap.

- `other`: The bitmap to compare with.

#### `override bool Equals(object obj)`

True if `obj` is a `Bitmap` with the same handle.

- `obj`: The object to compare with.

#### `override int GetHashCode()`

Hash of the handle.

#### `static bool operator ==(Bitmap a, Bitmap b)`

True if both handles refer to the same native bitmap.

#### `static bool operator !=(Bitmap a, Bitmap b)`

True if the handles differ.

Number of cells across (for grid-based tables).

#### `void Dispose()`

Frees the table and all its images.

## Font

```csharp
struct Font : IDisposable
```

A font (C: LCDFont, Lua: playdate.graphics.font). Fonts are .fnt/.png files compiled to .pft by pdc; the system fonts live in /System/Fonts.

#### `readonly LCDFont* Handle`

The native pointer.

#### `Font(LCDFont* handle)`

Wraps a native font pointer.

- `handle`: A native font pointer; this struct doesn't take ownership.

#### `bool IsNull { get; }`

True if this handle doesn't refer to a font.

#### `static Font Load(string path)`

Loads a font, e.g. "/System/Fonts/Asheville-Sans-14-Bold.pft" or "fonts/myfont" from the pdx. Stops the game with an error if the font can't be loaded.

- `path`: A .pft path, e.g. "/System/Fonts/Asheville-Sans-14-Bold.pft", or a font in the pdx without extension.

#### `static Font FromData(LCDFontData* data, bool wide, int dataLength)`

Wraps the contents of an uncompressed .pft file (without its 16-byte header) already in memory.

- `wide`: The header flag saying whether the font has glyphs above U+1FFFF.
- `data`: The font data; must stay valid while the font is used.
- `dataLength`: Size of `data` in bytes.

#### `int Height { get; }`

Line height in pixels.

#### `int GetTextWidth(string text, int tracking = 0)`

Width in pixels of a single line of `text`.

- `text`: One line of text.
- `tracking`: Extra pixels between characters.

#### `LCDFontPage* GetPage(uint character)`

Returns the page holding the glyphs for 256 characters around `character` (low-level glyph access).

- `character`: A Unicode code point.

#### `LCDFontGlyph* GetGlyph(uint character, out Bitmap bitmap, out int advance)`

Returns the glyph for a character, its bitmap (owned by the font) and its advance width in pixels.

- `character`: A Unicode code point.
- `bitmap`: Receives the glyph image (owned by the font).
- `advance`: Receives how far to move right after the glyph, in pixels.

#### `static int GetGlyphKerning(LCDFontGlyph* glyph, uint glyphCode, uint nextCode)`

Kerning adjustment in pixels between `glyphCode` and the following `nextCode`.

- `glyph`: The glyph of `glyphCode`.
- `glyphCode`: The current character's code point.
- `nextCode`: The following character's code point.

#### `void Dispose()`

Frees a font loaded with `Load`. Don't dispose fonts that are still set with `Graphics.SetFont`.
