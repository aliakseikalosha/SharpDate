## JsonHandler

```csharp
abstract class JsonHandler
```

Receives streaming JSON callbacks while a document is decoded (C: json_decoder), so large files can be read without building a tree. Override the methods you need and pass the handler to `Json.Decode(JsonHandler, string)` or `Json.DecodeFile`; for small documents `Json.Parse` is simpler.

#### `string Path { get; }`

Current position in the document, e.g. "web-app.servlet[1].init-param".

#### `virtual void DecodeError(string error, int lineNumber)`

Called when the JSON is invalid, with the message and line number. Decoding stops.

- `error`: Description of the problem.
- `lineNumber`: 1-based line in the document.

#### `virtual void WillDecodeSublist(string name, JsonValueType type)`

Called when an object (`JsonValueType.Table`) or array starts. `name` is its key, or "_root" for the document itself. Set `ReturnString` here to get it as raw text instead.

- `name`: Key of the object or array ("_root" for the document).
- `type`: `JsonValueType.Table` or `JsonValueType.Array`.

#### `virtual bool ShouldDecodeTableValueForKey(string key)`

Return false to skip the value for `key` (it is not decoded at all).

- `key`: The member name.

#### `virtual void DidDecodeTableValue(string key, JsonValue value)`

Called for each member of an object, after its value is decoded. For nested objects and arrays the value carries what `DidDecodeSublist` returned.

- `key`: The member name.
- `value`: Its value; valid only during the call.

#### `virtual bool ShouldDecodeArrayValueAtIndex(int position)`

Return false to skip the array element at 1-based `position`.

- `position`: 1-based element position.

#### `virtual void DidDecodeArrayValue(int position, JsonValue value)`

Array element (positions start at 1). Position 0 is a bare value at the root of the document.

- `position`: 1-based element position; 0 for a bare value at the root.
- `value`: Its value; valid only during the call.

#### `virtual void* DidDecodeSublist(string name, JsonValueType type)`

End of a table or array. The returned pointer is handed to the parent as the sublist's value (`JsonValueData.TableValue` / `JsonValueData.ArrayValue`).

- `name`: Key of the finished object or array.
- `type`: `JsonValueType.Table` or `JsonValueType.Array`.

#### `bool ReturnString { get; set; }`

Set to true to receive the current subtree as a raw string instead of decoding it.

#### `bool IsNull { get; }`

## Json


Reading and writing JSON (C: `pd->json`, Lua: `playdate.datastore` / `json`). `Parse` builds a `JsonNode` tree; `Decode(JsonHandler, string)` streams callbacks to a `JsonHandler`; `JsonWriter` writes JSON.

#### `static bool Decode(JsonHandler handler, string json)`

Decodes a JSON string with streaming callbacks. Returns false on error.

- `handler`: Receives the callbacks.
- `json`: The JSON text.

#### `static bool DecodeFile(JsonHandler handler, string path)`

Decodes a JSON file (read through `pd->file`) with streaming callbacks.

- `handler`: Receives the callbacks.
- `path`: Relative path (data folder first, then the pdx).

#### `static bool Decode(JsonHandler handler, PDFile file)`

Decodes from an open file, as the C example does with `pd->file->read` as the reader.

- `handler`: Receives the callbacks.
- `file`: An open file, read from its current position.

#### `static JsonNode Parse(string json)`

Parses a JSON string into a `JsonNode` tree (null on error).

- `json`: The JSON text.

#### `static JsonNode ParseFile(string path)`

Parses a JSON file into a `JsonNode` tree (null on error).

- `path`: Relative path (data folder first, then the pdx).

## JsonWriter

```csharp
class JsonWriter : IDisposable
```

Writes JSON text (C: json_encoder). Call the methods in document order, then `ToString`. The writer doesn't validate the structure.

#### `JsonWriter(bool pretty = false)`

Creates a writer. `pretty` adds line breaks and indentation.

- `pretty`: Indent and break lines for humans; false for compact output.

#### `JsonEncoder* Encoder { get; }`

The underlying C encoder.

#### `void StartArray()`

Writes [. Call `AddArrayMember` before each element.

#### `void AddArrayMember()`

Starts the next array element; then write its value.

#### `void EndArray()`

Writes ].

#### `void StartTable()`

Writes {. Call `AddTableMember` before each value.

#### `void AddTableMember(string name)`

Writes a member name; then write its value.

- `name`: The member name (escaped for you).

#### `void EndTable()`

Writes }.

#### `void WriteNull()`

Writes null.

#### `void WriteBool(bool value)`

Writes true or false.

- `value`: The boolean.

#### `void WriteInt(int value)`

Writes an integer.

- `value`: The integer.

#### `void WriteDouble(double value)`

Writes a number given as a double. Double-precision code crashes on the device (its FPU is single precision): use `WriteFloat` or `WriteInt` in games.

- `value`: The number.

#### `void WriteFloat(float value)`

Writes a number (formatted like `float.ToString()`). Safe on the device.

- `value`: The number; NaN and infinities are not valid JSON.

#### `void WriteString(string value)`

Writes a quoted, escaped string.

- `value`: The string (escaped for you).

#### `override string ToString()`

The JSON written so far.

#### `void Dispose()`

Frees the native encoder.
