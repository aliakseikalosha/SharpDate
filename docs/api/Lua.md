## Lua

```csharp
static class Lua
```

Wraps `pd->lua`: register C# functions and classes with the Lua runtime and exchange values. Register in `Game.InitializeLua`. Lua functions are `[UnmanagedCallersOnly]` static methods taking a `void*` (lua_State) and returning the number of results.

#### `static bool AddFunction(delegate* unmanaged[Cdecl]<void*, int> function, string name, out string error)`

Adds a global Lua function, e.g. "playdate.graphics.image.popcount".

- `function`: Static `[UnmanagedCallersOnly]` method returning the number of values pushed.
- `name`: Global name; dots create or extend tables, e.g. "mygame.distance".
- `error`: Receives the reason on failure.

#### `static bool RegisterClass(string name, ReadOnlySpan<LuaFunction> methods, out string error, bool isStatic = false)`

Registers a Lua class. Methods like `__gc`, `__index`, `new` are included in `methods`. Static classes have no instances (functions only).

- `name`: Class name as used in Lua (dots allowed), and in `PushObject`/`GetArgObject(int, string)`.
- `methods`: The methods and metamethods.
- `error`: Receives the reason on failure.
- `isStatic`: True for a plain table of functions instead of a class.

#### `static bool RegisterClass(string name, ReadOnlySpan<LuaFunction> methods, LuaVal* values, out string error, bool isStatic = false)`

Registers a class with constant values (e.g. enums) in addition to methods.

- `name`: Class name as used in Lua.
- `methods`: The methods and metamethods.
- `values`: Constants, ending with an entry whose name is null; must stay valid.
- `error`: Receives the reason on failure.
- `isStatic`: True for a plain table of functions instead of a class.

#### `static void PushFunction(delegate* unmanaged[Cdecl]<void*, int> function)`

Pushes a C# function onto the Lua stack (to return it, or before `CallFunction`).

- `function`: Static `[UnmanagedCallersOnly]` method.

#### `static bool IndexMetatable()`

For a class's __index function: looks the key up in the metatable first. If it returns true the value is on the stack and __index should return 1; otherwise do your own lookup.

#### `static void Stop()`

Stops the Lua run loop (playdate.update is no longer called).

#### `static void Start()`

#### `static LuaUDObject* PushObject(void* obj, string type, int nValues = 0)`

Pushes a native pointer as a Lua object of class `type`.

- `obj`: Native pointer stored in the object.
- `type`: A class registered with `RegisterClass(string, ReadOnlySpan<LuaFunction>, out string, bool)`.
- `nValues`: Number of user-value slots to reserve, 0 or more.

#### `static LuaUDObject* PushManagedObject(object obj, string type, int nValues = 0)`

Pushes a managed object as a Lua object. The object is kept alive by a GC handle until `ReleaseManagedObject` is called, typically from the class's `__gc` method.

- `obj`: The C# object (not null).
- `type`: A registered class name.
- `nValues`: Number of user-value slots to reserve, 0 or more.

#### `static void ReleaseManagedObject(int pos, string type)`

Frees the GC handle of a managed object at argument `pos` (call from __gc).

- `pos`: 1-based argument position (1 in __gc).
- `type`: The class name.

#### `static LuaUDObject* RetainObject(LuaUDObject* obj)`

Keeps a Lua object alive while C# holds on to it. Balance with `ReleaseObject`.

- `obj`: The userdata wrapper.

#### `static void ReleaseObject(LuaUDObject* obj)`

Releases a retain from `RetainObject`.

- `obj`: The userdata wrapper.

#### `static void SetUserValue(LuaUDObject* obj, uint slot)`

Stores the value on top of the stack in the object's user value `slot` (1-based; the object needs nValues slots from `PushObject`).

- `obj`: The userdata wrapper.
- `slot`: 1-based slot, up to nValues.

#### `static int GetUserValue(LuaUDObject* obj, uint slot)`

Pushes the object's user value `slot` and returns its stack position.

- `obj`: The userdata wrapper.
- `slot`: 1-based slot, up to nValues.

#### `static bool CallFunction(string name, int nargs, out string error)`

Calls a global Lua function with `nargs` arguments already pushed.

- `name`: Global function name; dots allowed, e.g. "game.onScore".
- `nargs`: Number of arguments already pushed, 0 or more.
- `error`: Receives the Lua error on failure.
