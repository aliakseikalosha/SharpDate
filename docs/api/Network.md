- `boardId`: The board's identifier.

#### `static bool GetScores(string boardId, Action<Score[], string> callback)`

- `boardId`: The board's identifier.

## Network

```csharp
static class Network
```

Wi-Fi state and control (C: `pd->network`, Lua: `playdate.network`). Connections are `HttpConnection` and `TcpConnection`; the device supports four at a time.

#### `static WifiStatus Status { get; }`

Whether the device is connected to an access point.

#### `static void SetEnabled(bool enabled, Action<NetErr> callback = null)`

Turns Wi-Fi on early (connecting can take 10 seconds or more), or off when the game no longer needs it. Wi-Fi also turns on by itself when needed and off after 30 seconds of inactivity.

- `callback`: Receives the result of connecting (only when enabling).
- `enabled`: True to connect now, false to turn Wi-Fi off.

## HttpConnection

```csharp
class HttpConnection : IDisposable
```

An HTTP or HTTPS connection to one server (C: HTTPConnection, Lua: playdate.network.http).

Ask for permission first with `RequestAccess`. Then send a request with `Get`, `Post` or `Query` and read the response in the events (`OnResponse` when data is available, `OnRequestComplete` at the end). Events run on the main thread. `Dispose` the connection when done.

#### `static AccessReply RequestAccess(string server, int port, bool useSsl, string purpose, Action<bool> callback)`

Asks the player for permission to connect to `server` (null = any server). Required before creating a connection; the callback receives the answer.

- `purpose`: Shown in the permission dialog.
- `server`: Host name, a parent domain of the hosts you'll use, or null for any server.
- `port`: Port, 1-65535; 0 for the default.
- `useSsl`: Request access for HTTPS.
- `callback`: Receives true if the player allowed access (main thread).

Returns: `AccessReply.Ask` while waiting for the player, or the remembered answer.

#### `HttpConnection(string server, int port, bool useSsl)`

Creates a connection; nothing is sent until a request is made.

- `port`: 0 for the default (80, or 443 with SSL).
- `server`: Host name, e.g. "example.com" (no scheme).
- `useSsl`: Use HTTPS.

#### `HTTPConnection* Handle { get; }`

The native connection.

#### `Action<string, string> OnHeaderReceived`

Raised for each response header (name, value).

#### `Action OnHeadersRead`

Raised when all headers are read; `ResponseStatus` and `GetProgress` are valid.

#### `Action OnResponse`

Raised when response data is available to `Read`.

#### `Action OnRequestComplete`

Raised when the whole response has arrived (when its length is known) or the request timed out.

#### `Action OnConnectionClosed`

Raised when the server closes the connection.

#### `int ConnectTimeout { set; }`

Milliseconds to wait for the connection to be made, above 0.

#### `bool KeepAlive { set; }`

Sends "Connection: keep-alive" so the connection can be reused for the next request.

#### `int ReadTimeout { set; }`

Milliseconds `Read` waits for data, above 0 (default 1000).

#### `int ReadBufferSize { set; }`

Size of the read buffer in bytes, above 0 (default 64 KB); `Read` returns at most this much at once.

#### `void SetByteRange(int start, int end)`

Requests only bytes `start` to `end` (a Range header).

- `start`: First byte, 0 or more.
- `end`: Last byte (included).

#### `NetErr Get(string path, string headers = null)`

Sends a GET request. `headers` are extra header lines ("Name: value\r\n...").

- `path`: Request path starting with '/', with the query string.
- `headers`: Extra header lines, each ending with "\r\n"; null for none.

#### `NetErr Post(string path, string headers, ReadOnlySpan<byte> body)`

Sends a POST request with a body.

- `path`: Request path starting with '/'.
- `headers`: Extra header lines, each ending with "\r\n"; null for none.
- `body`: The request body.

#### `NetErr Query(string method, string path, string headers, ReadOnlySpan<byte> body)`

Sends a request with any method (PUT, DELETE, ...).

- `method`: HTTP method, e.g. "PUT" or "DELETE".
- `path`: Request path starting with '/'.
- `headers`: Extra header lines, each ending with "\r\n"; null for none.
- `body`: The request body (may be empty).

#### `NetErr Error { get; }`

The connection's last error, or `NetErr.Ok`.

#### `void GetProgress(out int read, out int total)`

Bytes read so far and the total the server announced (if known).

- `read`: Receives bytes received so far.
- `total`: Receives the announced size, or 0 if unknown.

#### `int ResponseStatus { get; }`

The HTTP status code (200, 404, ...) once the headers are read.

#### `int BytesAvailable { get; }`

Bytes waiting to be read.

#### `int Read(Span<byte> buffer)`

Reads up to buffer.Length bytes, waiting up to `ReadTimeout` for more.

- `buffer`: Receives up to buffer.Length bytes (at most the read buffer size).

Returns: Bytes read, or a negative `NetErr`.

#### `string ReadAvailableText()`

Reads everything currently available as UTF-8 text.

#### `void Close()`

Closes the connection (it can be used for another request).

#### `void Dispose()`

Releases the connection.

## TcpConnection

```csharp
class TcpConnection : IDisposable
```

A TCP (optionally TLS) connection (C: TCPConnection, Lua: playdate.network.tcp). Ask for permission with `RequestAccess`, then `Open`. `Dispose` it when done.

#### `static AccessReply RequestAccess(string server, int port, bool useSsl, string purpose, Action<bool> callback)`

Asks the player for permission to connect to `server` (null = any) on `port` (0 = any).

- `server`: Host name, a parent domain, or null for any server.
- `port`: Port, 1-65535; 0 for any port.
- `useSsl`: Request access for TLS connections.
- `purpose`: Shown in the permission dialog.
- `callback`: Receives true if the player allowed access (main thread).

Returns: `AccessReply.Ask` while waiting for the player, or the remembered answer.

#### `TcpConnection(string server, int port, bool useSsl)`

Creates a connection; call `Open` to connect.

- `server`: Host name.
- `port`: Port, 1-65535.
- `useSsl`: Use TLS.

#### `TCPConnection* Handle { get; }`

The native connection.

#### `Action<NetErr> OnConnectionClosed`

Raised when the connection is closed, with the error (if any).

#### `NetErr Open(Action<NetErr> onOpen)`

Opens the connection; `onOpen` runs when it's established (or fails).

- `onOpen`: Receives `NetErr.Ok` or the error when connecting finishes (main thread).

#### `NetErr Close()`

Closes the connection (it can be opened again).

#### `NetErr Error { get; }`

The last error, or `NetErr.Ok`.

#### `int ConnectTimeout { set; }`

Milliseconds to wait for the connection, above 0.

#### `int ReadTimeout { set; }`

Milliseconds `Read` waits for data, above 0 (default 1000).

#### `int ReadBufferSize { set; }`

Read buffer size in bytes, above 0 (default 64 KB).

#### `int BytesAvailable { get; }`

Bytes waiting to be read.

#### `int SentBytesPending { get; }`

Bytes written but not yet sent (writes are asynchronous).

#### `int Read(Span<byte> buffer)`

Returns bytes read, or a negative `NetErr`.

- `buffer`: Receives up to buffer.Length bytes.

#### `int Write(ReadOnlySpan<byte> data)`

Returns bytes written, or a negative `NetErr`.

- `data`: The bytes to send.

#### `int Write(string text)`

Writes text as UTF-8.

- `text`: Text sent as UTF-8.

Returns: Bytes accepted, or a negative `NetErr`.

#### `string ReadAvailableText()`

Reads everything currently available as UTF-8 text.

#### `void Dispose()`

Releases the connection.
