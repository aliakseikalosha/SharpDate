## Sound

```csharp
static class Sound
```

The sound engine (C: `pd->sound`, Lua: `playdate.sound`): channels, custom sources, the microphone and headphones. The players, synths and effects are separate types.

Sound objects (`FilePlayer`, `Synth`, `SoundEffect` ...) are small structs around native pointers: copying one copies the handle. Dispose what you create. Volumes are 0-1, times are in seconds unless a parameter says samples, and the audio clock runs at 44,100 samples per second. Everything plays on `DefaultChannel` unless added to another channel. Finish and loop callbacks run on the main thread; callbacks that take native function pointers (custom sources, effects, signals, the microphone) run on the audio thread and must not allocate.

## SoundEffect

```csharp
struct SoundEffect : IDisposable
```

An effect applied to a `SoundChannel`: filters, bitcrusher, ring modulator, overdrive, delay line, or a custom native effect (C: SoundEffect, Lua: playdate.sound.effect). Add with `SoundChannel.AddEffect`; dispose after removing it.

#### `readonly Native.SoundEffect* Handle`

The native pointer.

#### `SoundEffect(Native.SoundEffect* handle) : this(handle, EffectKind.Custom)`

Wraps a native effect pointer (freed as a custom effect by `Dispose`).

- `handle`: A native effect pointer; this struct doesn't take ownership.

#### `static SoundEffect Create(delegate* unmanaged[Cdecl]<Native.SoundEffect*, int*, int*, int, int, int> process, void* userdata)`

Creates a custom effect. `process` runs on the audio thread with the left and right buffers (Q8.24 fixed point), the sample count and whether the buffers hold sound; it returns 1 if it changed the samples.

- `process`: Static `[UnmanagedCallersOnly]` function (effect, left, right, sampleCount, buffersActive) processing Q8.24 samples in place; returns 1 if it changed them. Audio thread.
- `userdata`: Stored as `Userdata`.

#### `float Mix { set; }`

Wet/dry mix: 1 replaces the input with the effect's output, 0 leaves the effect out.

#### `SynthSignalValue MixModulator { get; set; }`

A signal modulating the mix.

#### `void* Userdata { get; set; }`

A free pointer for custom effects.

#### `static SoundEffect TwoPoleFilter(TwoPoleFilterType type, float frequency, float resonance = 0)`

Creates a two-pole (resonant) filter.

- `frequency`: Cutoff or center frequency in Hz.
- `resonance`: Resonance, 0-1.
- `type`: Filter shape.

#### `static SoundEffect OnePoleFilter(float parameter)`

Creates a one-pole filter: `parameter` from -1 to 0 is low-pass, 0 to 1 high-pass.

- `parameter`: -1 to 0 = low-pass (lower = darker), 0 to 1 = high-pass.

#### `static SoundEffect BitCrusher(float depth, float downsampling)`

Creates a bitcrusher.

- `depth`: Amplitude quantizing, 0 (none) to 1 (1-bit).
- `downsampling`: Sample-rate reduction, 0 (none) to 1 (silence).

#### `static SoundEffect RingModulator(float frequency)`

Creates a ring modulator with a modulation frequency in Hz.

- `frequency`: Modulation frequency in Hz.

#### `static SoundEffect Overdrive(float gain, float limit)`

Creates an overdrive: the input is amplified by `gain` and clipped at `limit`.

- `gain`: Amplification before clipping, 1 or more (higher = more distortion).
- `limit`: Level where the signal clips, 0-1.

#### `static SoundEffect DelayLine(int lengthInSamples, bool stereo, float feedback)`

Creates a delay line `lengthInSamples` long (44100 = one second). Its output is the full delay; add more outputs with `AddDelayTap`.

- `feedback`: How much of the output is fed back, 0-1.
- `lengthInSamples`: Delay length in samples (44100 = one second); taps can't be further than this.
- `stereo`: Keep left and right separate.

#### `SoundSource AddDelayTap(int delayInSamples)`

For a delay line: adds a tap that plays the delayed signal at `delayInSamples` (at most the line's length). The tap is a `SoundSource` and can go on any channel.

- `delayInSamples`: Tap position in samples, up to the delay line's length.

#### `void Dispose()`

Frees the effect with the free function matching its type.
