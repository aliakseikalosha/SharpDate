# Sprites and collisions

Source: [`src/SharpDate/Sprite.cs`](../../src/SharpDate/Sprite.cs). Generated by `tools/generate_api_docs.py`.

## Sprite

```csharp
class Sprite : IDisposable
```

A sprite: an image (or custom drawing) with a position, a Z order and an optional collision rectangle, managed by the sprite system (C: LCDSprite, Lua: playdate.graphics.sprite).

Subclass it and override `Update`, `Draw` (with `HasDrawFunction`) or `CollisionResponse` (with `HasCollisionResponse`). Call `Add` to put it on screen and `Sprites.UpdateAndDrawSprites` once per frame. A sprite stays alive (it is referenced by the sprite system) until you call `Dispose`, which removes and frees it; disposing inside its own `Update` is fine. Don't use a sprite after disposing it. Positions refer to the sprite's center unless `SetCenter` changes it.

#### `Sprite()`

Creates a native sprite and attaches it to this object. It isn't visible until `Add`.

#### `LCDSprite* Handle { get; }`

The native sprite (null after `Dispose`), for the raw API.

#### `static Sprite FromHandle(LCDSprite* handle)`

Returns the managed sprite for a native handle, or null if it was not created by SharpDate.

- `handle`: A native sprite (null returns null).

#### `void Add()`

Adds the sprite to the display list.

#### `void Remove()`

Removes the sprite from the display list without freeing it; `Add` brings it back.

#### `PDRect Bounds { get; set; }`

The sprite's bounding rectangle in world coordinates (position and size). Setting it moves and resizes the sprite.

#### `void MoveTo(float x, float y)`

Moves the sprite so that its center point (see `SetCenter`) is at (x, y). Doesn't check collisions.

- `x`: World x for the center point.
- `y`: World y for the center point.

#### `void MoveBy(float dx, float dy)`

Moves the sprite by (dx, dy). Doesn't check collisions.

- `dx`: Horizontal distance (positive = right).
- `dy`: Vertical distance (positive = down).

#### `void GetPosition(out float x, out float y)`

The position of the sprite's center point.

- `x`: Receives the center point's x.
- `y`: Receives the center point's y.

#### `float X { get; }`

X of the sprite's center point.

#### `float Y { get; }`

Y of the sprite's center point.

#### `void SetSize(float width, float height)`

Sets the size used for `Bounds` when the sprite has no image (e.g. custom-drawn sprites).

- `width`: Width in pixels, 0 or more.
- `height`: Height in pixels, 0 or more.

#### `void SetCenter(float x, float y)`

Sets which point of the sprite `MoveTo` positions, as fractions of its size: 0.5, 0.5 (default) is the middle, 0, 0 the top-left corner.

- `x`: 0 (left edge) to 1 (right edge); 0.5 = middle.
- `y`: 0 (top edge) to 1 (bottom edge); 0.5 = middle.

#### `void GetCenter(out float x, out float y)`

Gets the center point set with `SetCenter`.

- `x`: Receives the horizontal center, 0-1.
- `y`: Receives the vertical center, 0-1.

#### `Bitmap Image { get; set; }`

The sprite's image; the sprite's size follows the image. The sprite does not own the bitmap: keep it alive while the sprite uses it and dispose it yourself afterwards (several sprites can share one).

#### `void SetImage(Bitmap image, BitmapFlip flip)`

Sets the image and how it is flipped.

- `image`: The image (not owned by the sprite); a null bitmap removes it.
- `flip`: Mirroring.

#### `short ZIndex { get; set; }`

Drawing order, -32768 to 32767: sprites with a higher Z index are drawn on top. Default 0.

#### `DrawMode DrawMode { set; }`

How the image is drawn (e.g. `DrawMode.WhiteTransparent`).

#### `BitmapFlip ImageFlip { get; set; }`

How the image is mirrored.

#### `bool Visible { get; set; }`

Whether the sprite is drawn. Invisible sprites still update and collide.

#### `bool Opaque { set; }`

Declares that the sprite covers everything below it, so the sprite system can skip redrawing what's underneath. Set automatically for images without a mask.

#### `bool UpdatesEnabled { get; set; }`

Whether `Update` is called. Disabled sprites are still drawn.

#### `bool IgnoresDrawOffset { set; }`

Draws the sprite in screen coordinates, ignoring `Graphics.SetDrawOffset` (for HUD elements). Collisions still use world coordinates.

#### `byte Tag { get; set; }`

A free number (0-255) to identify kinds of sprites, e.g. in collision handling.

#### `void SetClipRect(LCDRect clipRect)`

Only draws the part of the sprite inside `clipRect` (screen coordinates).

- `clipRect`: Area in screen coordinates.

#### `void ClearClipRect()`

Removes the sprite's clip rect.

#### `void MarkDirty()`

Forces the sprite to be redrawn next frame (needed after changing what a custom `Draw` draws).

#### `void MarkDirtyRect(PDRect rect)`

Marks part of the sprite (relative to its top-left corner) for redrawing.

- `rect`: Area relative to the sprite's top-left corner.

#### `void SetStencilImage(Bitmap stencil, bool tile)`

Only draws the sprite where `stencil` is white. The stencil is in screen coordinates and doesn't move with the sprite; tiled stencils must be a multiple of 32 pixels wide.

- `stencil`: White = draw, black = hide; in screen coordinates.
- `tile`: Repeat the stencil (it must be a multiple of 32 pixels wide).

#### `void SetStencilPattern(ReadOnlySpan<byte> pattern)`

Sets an 8x8 repeating stencil: 8 bytes, one per row, bit 7 = leftmost pixel, 1 = draw.

- `pattern`: Up to 8 row bytes (missing rows are fully drawn); bit 7 = leftmost pixel, 1 = draw.

#### `void ClearStencil()`

Removes the sprite's stencil.

#### `TileMap Tilemap { get; set; }`

Uses a tile map as the sprite's image (not owned by the sprite).

#### `bool CollisionsEnabled { get; set; }`

Whether the sprite takes part in collisions (default true; it also needs a `CollideRect`).

#### `PDRect CollideRect { get; set; }`

The area that collides, relative to the sprite's top-left corner, e.g. `new PDRect(0, 0, image.Width, image.Height)`. A sprite without a collide rect never collides.

#### `void ClearCollideRect()`

Removes the collide rect (the sprite no longer collides).

#### `CollisionList MoveWithCollisions(float goalX, float goalY, out float actualX, out float actualY)`

Moves toward (goalX, goalY), stopping, sliding or bouncing at other sprites' collide rects according to `CollisionResponse`, and reports what it hit. Dispose the returned list (a `using` does it).

- `actualX`: Where the sprite ended up.
- `goalX`: Where the center point should go (x).
- `goalY`: Where the center point should go (y).
- `actualY`: Where the sprite ended up (y).

Returns: The collisions, in the order they happened.

#### `CollisionList CheckCollisions(float goalX, float goalY, out float actualX, out float actualY)`

Computes the result of `MoveWithCollisions` without moving the sprite. Dispose the returned list.

- `goalX`: Target x of the center point.
- `goalY`: Target y of the center point.
- `actualX`: Where the sprite would end up (x).
- `actualY`: Where the sprite would end up (y).

#### `SpriteList OverlappingSprites()`

The sprites whose collide rects currently overlap this one's. Dispose the returned list.

#### `void Dispose()`

Removes the sprite from the display list and frees it. Safe to call more than once and from the sprite's own `Update`. Doesn't free the sprite's image.

## Sprites

```csharp
static class Sprites
```

The sprite system as a whole: drawing all sprites, queries and global settings (C: `pd->sprite`, Lua: `playdate.graphics.sprite` static functions).

#### `static void UpdateAndDrawSprites()`

Calls `Sprite.Update` on every sprite in the display list, then redraws the areas that changed. Call once per frame from `Game.Update`.

#### `static void DrawSprites()`

Draws the sprites without updating them.

#### `static void SetAlwaysRedraw(bool flag)`

Redraws every sprite every frame instead of tracking dirty areas. Faster when many sprites move at once.

- `flag`: True = redraw everything every frame, false = only dirty areas (default).

#### `static void AddDirtyRect(LCDRect rect)`

Marks a screen area for redrawing (drawing functions do this automatically).

- `rect`: Area in screen coordinates.

#### `static void RemoveAllSprites()`

Removes all sprites from the display list (they aren't freed; dispose them separately).

#### `static int Count { get; }`

Number of sprites in the display list.

#### `static void SetClipRectsInRange(LCDRect clipRect, int startZ, int endZ)`

Sets a clip rect on every sprite whose Z index is between startZ and endZ (inclusive).

- `clipRect`: Area in screen coordinates.
- `startZ`: Lowest Z index affected, -32768 to 32767.
- `endZ`: Highest Z index affected (included).

#### `static void ClearClipRectsInRange(int startZ, int endZ)`

Clears the clip rects of sprites with Z index between startZ and endZ (inclusive).

- `startZ`: Lowest Z index affected.
- `endZ`: Highest Z index affected (included).

#### `static void ResetCollisionWorld()`

Rebuilds the collision data from scratch (resetting it to its default state).

#### `static SpriteList QuerySpritesAtPoint(float x, float y)`

Sprites whose collide rects contain the point. Dispose the returned list.

- `x`: World x.
- `y`: World y.

#### `static SpriteList QuerySpritesInRect(float x, float y, float width, float height)`

Sprites whose collide rects intersect the rectangle. Dispose the returned list.

- `x`: Left edge in world coordinates.
- `y`: Top edge.
- `width`: Width.
- `height`: Height.

#### `static SpriteList QuerySpritesAlongLine(float x1, float y1, float x2, float y2)`

Sprites whose collide rects the line from (x1, y1) to (x2, y2) crosses. Dispose the returned list.

- `x1`: Start x.
- `y1`: Start y.
- `x2`: End x.
- `y2`: End y.

#### `static SpriteQueryList QuerySpriteInfoAlongLine(float x1, float y1, float x2, float y2)`

Like `QuerySpritesAlongLine`, with the entry and exit points. Slower; dispose the result.

- `x1`: Start x.
- `y1`: Start y.
- `x2`: End x.
- `y2`: End y.

#### `static SpriteList AllOverlappingSprites()`

All overlapping pairs: entries 0 and 1 overlap, 2 and 3 overlap, and so on. Dispose the returned list.
