System services: logging, buttons, crank, accelerometer, time, the system menu, battery and device settings (C: `pd->system`; in Lua these are spread over `playdate.*`).

#### `static void Log(string message)`

Prints a line to the console: the Simulator's console, or the serial port of a device (Lua: print).

- `message`: The text; may contain line breaks. null prints an empty line.

#### `static void Log(ReadOnlySpan<byte> utf8Message)`

Prints a UTF-8 literal, e.g. `Sys.Log("hello"u8)`, without creating a string.

- `utf8Message`: UTF-8 text without a terminating zero, e.g. `"hello"u8`.

#### `static void Error(string message)`

Reports an error: prints it in red and stops the game (the device shows the message). Use for unrecoverable problems; unhandled C# exceptions end up here too.

- `message`: The error text shown to the player and printed to the console.

#### `static void DrawFPS(int x, int y)`

Draws the current frames per second at (x, y) (Lua: playdate.drawFPS).

- `x`: Left edge in screen pixels, 0-399.
- `y`: Top edge in screen pixels, 0-239.

#### `static uint CurrentTimeMilliseconds { get; }`

Milliseconds since an arbitrary point; consistent while the game runs, but it doesn't advance while the device sleeps. Use for timing, not for dates.

#### `static uint GetSecondsSinceEpoch(out uint milliseconds)`

Seconds (and milliseconds) since 2000-01-01 00:00 UTC, from the device clock.

- `milliseconds`: Receives the milliseconds within the current second, 0-999.

#### `static uint SecondsSinceEpoch { get; }`

Seconds since 2000-01-01 00:00 UTC, from the device clock (which the user can change; see `GetServerTime`).

#### `static float ElapsedTime { get; }`

Seconds since `ResetElapsedTime`, with microsecond resolution. Good for profiling.

#### `static void ResetElapsedTime()`

Restarts the high-resolution timer read by `ElapsedTime`.

#### `static int TimezoneOffset { get; }`

The time zone's offset from UTC in seconds.

#### `static bool ShouldDisplay24HourTime { get; }`

True if the user prefers 24-hour time.

#### `static PDDateTime ConvertEpochToDateTime(uint epoch)`

Converts seconds since 2000-01-01 to a calendar date and time (UTC; add `TimezoneOffset` for local time).

- `epoch`: Seconds since 2000-01-01 00:00 UTC.

#### `static uint ConvertDateTimeToEpoch(PDDateTime dateTime)`

Converts a calendar date and time to seconds since 2000-01-01.

- `dateTime`: The date and time; month 1-12, day 1-31, hour 0-23, minute and second 0-59 (the weekday is ignored).

#### `static void Delay(uint milliseconds)`

Blocks the game for `milliseconds`. Rarely useful; the frame loop keeps time for you.

- `milliseconds`: How long to block, in milliseconds.

#### `static void GetButtonState(out Buttons current, out Buttons pushed, out Buttons released)`

Current button state plus buttons pushed and released since the last update.

- `current`: Buttons held down right now.
- `pushed`: Buttons that went down since the previous frame (not missed even if already released).
- `released`: Buttons that went up since the previous frame.

#### `static Buttons ButtonsCurrent { get; }`

Buttons currently held down.

#### `static Buttons ButtonsPushed { get; }`

Buttons pushed since the previous update.

#### `static Buttons ButtonsReleased { get; }`

Buttons released since the previous update.

#### `static bool IsPressed(Buttons button)`

True while `button` is held (any of them, if several are combined).

- `button`: One button, or several combined with | (true if any of them is held).

#### `static bool JustPressed(Buttons button)`

True if `button` went down since the last frame. Use this for actions like jumping.

- `button`: One button, or several combined with | (true if any of them was pushed).

#### `static bool JustReleased(Buttons button)`

True if `button` went up since the last frame.

- `button`: One button, or several combined with | (true if any of them was released).

#### `delegate int ButtonHandler(Buttons button, bool down, uint when)`

A button event handler for `SetButtonCallback`: the button, whether it went down, and the time of the event in milliseconds (`CurrentTimeMilliseconds` scale). Return 0.

- `button`: The single button the event is about.
- `down`: True when the button went down, false when it went up.
- `when`: Time of the event in milliseconds, on the `CurrentTimeMilliseconds` clock.

Returns: 0 (non-zero is reserved for reporting an error).

#### `static void SetButtonCallback(ButtonHandler handler, int queueSize = 5)`

Receives every button press and release as an event instead of polling with `GetButtonState`, so quick taps between frames aren't missed. The handler is called once per event that happened during the previous frame. Pass null to remove the handler.

- `queueSize`: How many events to buffer per frame (5 is enough at 30 fps; raise it for lower frame rates).
- `handler`: Called once per event; null removes the callback and returns to polling only.

#### `static float CrankAngle { get; }`

The crank's position in degrees, 0-360: 0 points up, and the value grows as the crank turns clockwise (seen from the right side of the device).

#### `static float CrankChange { get; }`

Degrees the crank turned since the last time this was read (negative = counter-clockwise). Read it once per frame.

#### `static bool IsCrankDocked { get; }`

True when the crank is folded into the device.

#### `static bool SetCrankSoundsDisabled(bool disabled)`

Turns off the system sounds played when the crank is docked or undocked.

- `disabled`: True to silence the dock/undock sounds, false to restore them.

Returns: The previous setting.

#### `static void SetPeripheralsEnabled(Peripherals mask)`

Switches sensors on or off. The accelerometer is off by default to save power.

- `mask`: The peripherals to switch on; everything not in the mask is switched off. `Peripherals.None` turns everything off.

#### `static void GetAccelerometer(out float x, out float y, out float z)`

The last accelerometer reading in g on each axis (enable it first with `SetPeripheralsEnabled`). Lying flat, face up, it reads about (0, 0, 1).

- `x`: Acceleration along the screen's horizontal axis in g (about -1 to 1 when held still; more when shaken).
- `y`: Acceleration along the screen's vertical axis in g.
- `z`: Acceleration perpendicular to the screen in g (about 1 lying face up).

#### `static Language Language { get; }`

The device's language.

#### `static bool Flipped { get; }`

True if the user turned on the "upside down" (left-handed) setting.

#### `static bool ReduceFlashing { get; }`

True if the user asked for reduced flashing; avoid strobing effects then.

#### `static void SetAutoLockDisabled(bool disabled)`

Stops the device from locking after 3 minutes without input (for games where the player may only watch). Re-enable it when that part of the game ends.

- `disabled`: True to stop the 3-minute auto lock, false to enable it again (which restarts the timer).

#### `static float BatteryPercentage { get; }`

Battery charge, 0 (empty) to 100 (full).

#### `static float BatteryVoltage { get; }`

Battery voltage.

#### `static float Volume { get; }`

The system volume, 0-1. If it's 0, the game can skip waiting for sounds to finish.

#### `static PDInfo SystemInfo { get; }`

OS version, language and the SDK version the game was built with.

#### `static void ClearICache()`

Flushes the CPU instruction cache; only needed by code that generates machine code at run time.

#### `static string GetLocalizedText(string key, Language language = Language.System)`

Looks up `key` in the game's .strings file for the language (en.strings, jp.strings compiled into the pdx).

- `key`: The key as written in the .strings file.
- `language`: Which language's file to use; `Language.System` (default) uses the device language and falls back to the other one.

Returns: The text, or null if the key or file doesn't exist.

#### `static string GetLaunchArgs(out string path)`

The arguments the game was started with (from the Simulator command line, the device's run command or `RestartGame`), and the game's path.

- `path`: Receives the path of the running game's pdx.

Returns: The launch argument string, or null if there was none.

#### `static void RestartGame(string launchArgs = null)`

Restarts the game with a fresh runtime state; `launchArgs` is available afterwards from `GetLaunchArgs`.

- `launchArgs`: Any text to hand to the restarted game (null for none).

#### `static void ExitToLauncher()`

Quits to the launcher; the game receives `SystemEvent.Terminate` first.

#### `static void GetServerTime(Action<string, string> callback)`

Asks Panic's server for the current time, a clock the user can't change. The callback receives the time as text (seconds since 2000-01-01 UTC) or an error message. Needs Wi-Fi.

- `callback`: Receives (time, error): the time as decimal seconds since 2000-01-01 UTC and null, or null and an error message. Runs on the main thread.

#### `static void SetSerialMessageCallback(Action<string> callback)`

Receives messages sent to the device over USB with the `msg` serial command (in the Simulator: type `!msg text` in the console). Pass null to stop.

- `callback`: Receives each message text; null stops receiving.

#### `static void SetMenuImage(Bitmap bitmap, int xOffset = 0)`

Sets the 400x240 image shown next to the system menu while the game is paused; keep the important part in the left 200 pixels. Call it when `SystemEvent.Pause` arrives.

- `xOffset`: 0-200: how far the image slides left as the menu opens.
- `bitmap`: A 400x240 bitmap, or a null bitmap (`default`) to remove the image. The game keeps ownership; keep it alive while it is set.

#### `static MenuItem AddMenuItem(string title, Action<MenuItem> callback)`

Adds an action item to the system menu (at most three custom items in total). Choosing it closes the menu and runs `callback`.

- `title`: Text shown in the menu; keep it short (about 10 characters fit).
- `callback`: Called with the item after the menu closes when the player chose it; may be null.

Returns: The item, or one whose `MenuItem.NativeHandle` is null if the menu is full (3 items).

#### `static MenuItem AddCheckmarkMenuItem(string title, bool value, Action<MenuItem> callback)`

Adds an on/off item to the system menu. `callback` runs when the menu closes if the value changed; read `MenuItem.Checked`.

- `title`: Text shown in the menu; keep it short.
- `value`: Initial state: true = checked.
- `callback`: Called with the item after the menu closes if the player changed it; may be null.

Returns: The item, or one whose `MenuItem.NativeHandle` is null if the menu is full (3 items).

#### `static MenuItem AddOptionsMenuItem(string title, string[] options, Action<MenuItem> callback)`

Adds an item that cycles through `options` (keep them short). `callback` runs when the menu closes; `MenuItem.Value` is the selected index.

- `title`: Text shown in the menu; keep it short.
- `options`: The choices, at least one; keep them short (title and option share one line).
- `callback`: Called with the item after the menu closes if the player changed it; may be null.

Returns: The item, or one whose `MenuItem.NativeHandle` is null if the menu is full (3 items).

#### `static void RemoveAllMenuItems()`

Removes all the game's menu items.
