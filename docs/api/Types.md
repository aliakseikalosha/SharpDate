# Enums and data structures

Source: [`src/SharpDate/Types.cs`](../../src/SharpDate/Types.cs). Generated by `tools/generate_api_docs.py`.

Restates interface facts from the Playdate SDK headers, which remain Panic's; SharpDate's own contributions to this page are 0BSD. See [LICENSING.md](../../LICENSING.md).

## SystemEvent

```csharp
enum SystemEvent
```

A system event sent to the game (C: PDSystemEvent). Received in `Game.OnEvent`; `Init` and `InitLua` are handled by SharpDate and call `Initialize` / `InitializeLua` instead.

| Value | Meaning |
|---|---|
| `Init` | The game is starting. The API is ready; SharpDate creates your `Game` here. |
| `InitLua` | Lua is ready (only for games with a main.lua). Register Lua functions now. |
| `Lock` | The device is being locked. |
| `Unlock` | The device was unlocked. |
| `Pause` | The system menu opened. A good moment to call `Sys.SetMenuImage`. |
| `Resume` | The system menu closed. |
| `Terminate` | The game is about to quit (back to the launcher or the device shutting down). Save state now. |
| `KeyPressed` | Simulator only: a key was pressed on the computer's keyboard; `arg` is the key code. |
| `KeyReleased` | Simulator only: a key was released; `arg` is the key code. |
| `LowPower` | The battery is low. |
| `MirrorStarted` | Mirroring (Playdate Mirror app) started. |
| `MirrorEnded` | Mirroring ended. |

## LCDRect

```csharp
struct LCDRect
```

An integer rectangle given by its edges (C: LCDRect). `Right` and `Bottom` are exclusive. Used for clip rects and dirty rects; sprites use the float `PDRect`.

#### `int Left`

Left edge (inclusive).

#### `int Right`

Right edge (exclusive).

#### `int Top`

Top edge (inclusive).

#### `int Bottom`

Bottom edge (exclusive).

#### `LCDRect(int left, int top, int right, int bottom)`

Creates a rectangle from its edges. Note the argument order: left, top, right, bottom.

- `left`: Left edge (included).
- `top`: Top edge (included).
- `right`: Right edge (excluded), at least `left`.
- `bottom`: Bottom edge (excluded), at least `top`.

#### `static LCDRect Make(int x, int y, int width, int height)`

Creates a rectangle from a position and a size.

- `x`: Left edge.
- `y`: Top edge.
- `width`: Width, 0 or more.
- `height`: Height, 0 or more.

#### `LCDRect Translate(int dx, int dy)`

Returns the rectangle moved by (dx, dy).

- `dx`: Horizontal offset.
- `dy`: Vertical offset.

#### `int Width { get; }`

Right - Left.

#### `int Height { get; }`

Bottom - Top.

## JsonValue

```csharp
struct JsonValue
```

A value handed to `JsonHandler` callbacks (C: json_value). Valid only during the callback; copy what you need (the accessors below convert like the C json_intValue / json_floatValue ... helpers).

#### `byte RawType`

The `JsonValueType` as stored by the C decoder.

#### `JsonValueData Data`

The raw payload.

#### `JsonValueType Type { get; }`

The kind of value.

#### `object ToObject()`

Boxes the value: null, bool, int, float or string (null for arrays and tables).

#### `int IntValue { get; }`

The value as an int: integers as is, floats truncated, numeric strings parsed, true = 1, otherwise 0.

#### `float FloatValue { get; }`

The value as a float: numbers as is, true = 1, otherwise 0.

#### `bool BoolValue { get; }`

The value as a bool: non-empty strings and non-zero numbers are true.

#### `string StringValue { get; }`

The string, or null if the value isn't a string.

#### `override string ToString()`

A short text form ("null", "true", the number, the string, "array" or "table").

| `NotConnectedToAP = -16` | Not connected to a Wi-Fi access point. |
| `NotImplemented = -17` | Not supported (e.g. in this Simulator). |
