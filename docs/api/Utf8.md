## Utf8

UTF-8 helpers for passing strings to the Playdate C API.

Most wrapper methods accept `string` and convert it into one of a few reusable native scratch buffers (no allocation per call). Pointers returned by `Arg` are only valid until the next call that uses the same slot.

#### `static byte* Arg(string value, int slot = 0)`

Converts `value` to NUL-terminated UTF-8 in scratch slot `slot`.

- `value`: The string (null returns null).
- `slot`: Scratch buffer 0-3; use different slots for strings passed in the same call.

#### `static byte* Alloc(string value)`

Allocates a NUL-terminated UTF-8 copy with the Playdate allocator. Free with `Free`.

- `value`: The string (null returns null).

#### `static void Free(byte* p)`

Frees memory from `Alloc`.

- `p`: A pointer from `Alloc`, or null.

#### `static string ToString(byte* p)`

Converts a NUL-terminated UTF-8 C string to a managed string (null for a null pointer).

- `p`: A NUL-terminated UTF-8 string, or null.

#### `static string ToString(byte* p, int length)`

Converts `length` UTF-8 bytes to a managed string.

- `p`: UTF-8 bytes, or null.
- `length`: Number of bytes, 0 or more.

#### `static int CodePointCount(ReadOnlySpan<char> text)`

Number of code points in a UTF-16 string (what the Playdate text APIs expect as a length).

- `text`: UTF-16 text.

#### `static int CodePointCount(ReadOnlySpan<byte> utf8)`

Number of code points in a UTF-8 byte sequence.

- `utf8`: UTF-8 text.
